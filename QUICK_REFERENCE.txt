🔄 DATA FLOW DIAGRAM
═════════════════════════════════════════════════════════════════════════════

USER REGISTERS
    ↓
POST /api/auth/register
    ↓
UserService.createUser()
    ↓
INSERT INTO users (id, deviceId, publicKey...)
    ↓
Return userId

ORDER CREATED
    ↓
POST /api/delivery/orders
    ↓
DeliveryService.createDelivery()
NFTService.createNFTRecord()
    ↓
INSERT INTO deliveries (id, orderId, status: "pending"...)
INSERT INTO nft_records (deliveryId, status: "pending"...)
    ↓
Return deliveryId

GPS LOCATION UPDATE (EVERY 5-10 SECONDS)
    ↓
POST /api/delivery/{deliveryId}/location
    ↓
LocationService.recordLocation()
    ↓
INSERT INTO location_history (deliveryId, latitude, longitude, timestamp)
    ↓
Calculate distance to destination
    ↓
IF distance < 100m:
  UPDATE deliveries SET status = 'in_transit'
    ↓
Return current status + ETA

DELIVERY COMPLETED
    ↓
POST /api/delivery/{deliveryId}/complete
    ↓
DeliveryService.updateDeliveryStatus()
    ↓
UPDATE deliveries SET status = 'completed', completedTime = NOW()
    ↓
(Phase 4) Mint NFT on Solana
UPDATE nft_records SET status = 'minted', transactionHash = '...'
    ↓
Return success
