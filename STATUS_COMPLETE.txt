🔄 REAL-TIME DELIVERY TRACKING FLOW
═════════════════════════════════════════════════════════════════════════════

Delivery Person Phone:
    📍 GPS Location captured every 5-10 seconds
        ↓
    POST /api/delivery/{deliveryId}/location
        ↓
Backend Processing:
    ✅ Save location to LocationHistory table
    ✅ Calculate distance to customer
    ✅ Check distance thresholds
    ✅ Auto-update status if needed:
        - pending → in_transit (when < 500m from start)
        - in_transit → arrived (when < 100m from end)
    ✅ Calculate ETA based on current speed
        ↓
    🔴 EMIT WebSocket Event 'delivery:location-updated'
    🔴 EMIT to room 'location-changed'
        ↓
WebSocket Broadcasting:
    📡 Sent to ALL connected clients (instant!)
    📦 Includes: coordinates, status, distance, ETA, speed
        ↓
Frontend Browser:
    📱 Receives 'delivery:location-updated' event
    📍 Updates map marker (smooth animation)
    📊 Updates distance counter
    ⏱️  Updates ETA countdown
    ✨ NO PAGE REFRESH NEEDED!
    ✨ COMPLETELY REAL-TIME!
